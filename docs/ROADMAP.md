# 迭代路线

## 0.1 — 可运行框架

SwiftUI 工作台、原创示例、TXT、本地位置保存、官方电子书架、热门划线评论适配、WebKit 全文、Keychain、测试与 CI。

## 0.2 — 真实账号联调

- 用用户授权的真实 API Key 验证书架、章节定位、热门划线和评论分页；保留脱敏回包 fixtures。
- 验证网页扫码登录、重启保留、窗口导航、会话过期、退出账号和登录弹窗。
- 处理服务端版本升级与 schema 变化，完善账号错误提示。
- 接入个人划线及个人想法；热门划线与个人划线明确分开。
- 研究官网全文选择事件是否能稳定映射到服务端 range，再决定是否原生侧栏联动。不要用 Swift 字符偏移猜测服务端位置。

## 0.3 — 本地电子书

- EPUB 容器、OPF/spine/目录、资源 URL scheme 和 WebKit 排版 provider。
- PDFKit 文档 provider、目录与页级位置。
- 引入可迁移的 LibraryRepository/ReadingLocationStore，补充导入、删除、书库恢复。
- 搜索、章节目录、书签；支持键盘阅读与 VoiceOver。

## 0.4 — 阅读打磨

- 字体感知的真实分页与双页阅读（现阶段“分组翻页”每页四段）。
- 字体、行距、页宽、段距控制与模式切换位置对齐。
- 本地高亮和笔记，按稳定段落 ID + 本地文本范围定位。

## 1.0 — 分发

- 应用图标、版本升级、签名与公证、Universal Binary、DMG。
- 必要的 App Sandbox entitlements 验证；当前原型是非沙盒本地 app。
- 本地格式和在线账号的集成验收、无障碍与性能优化。

每次迭代使用独立 OpenSpec change；完成后同步主规格并归档。未提供公开全文接口前，不把原生微信读书全文渲染列为已支持能力。
