# 首版验收

## 自动化

`bash scripts/test.sh` 覆盖：TXT 换行规范化及 JSON 持久化、章节/书籍/range 定位隔离、官方 URL 校验、Gateway 鉴权与平铺请求、热门划线映射、评论范围匹配、分页游标、空结果、鉴权/升级/格式错误和重复游标保护。脚本兼容 Xcode 与仅安装 Command Line Tools 的开发环境。

`swift build` 编译全部界面；`bash scripts/package-app.sh` 构建 release 应用并验证本地签名。UI 交互与真实账号测试分别记录，自动 fixtures 不代替真实接入。

## 本地手动验收

- [x] 打开 app，显示原创示例书，评论面板明确标记“示例讨论”。
- [x] 点击不同段落，仅展示对应示例想法。
- [ ] 四种主题、字号、滚动、分组翻页、专注模式可切换；可以退出专注模式。
- [x] 分组翻页第一页不能再往前、末页不能再往后。
- [x] 导入 UTF-8 TXT，重启后仍可打开。
- [ ] 空文件或过大文件显示错误（核心空内容已单测，UI 待验收）。
- [x] 点击段落后，重启并重新打开该书恢复所选段落。
- [ ] 分组翻页重启恢复所在页。
- [x] 无 API Key 时保留本地书库，不用示例冒充微信读书数据。

## 真实账号验收（需要用户自己登录）

- [ ] 官网获取 API Key，在 app 保存并同步；Keychain 中存在条目，偏好、书库与仓库中没有 Key。
- [ ] 电子书架与本人账号中的电子书一致；有声书与文章收藏本轮不显示。
- [ ] 选书获取热门划线；点击原文，评论与微信读书同一原文位置一致。
- [ ] 有更多评论时能够继续加载；上游页码不前进时显示错误。
- [ ] 快速切换划线、书籍和账号，慢响应不会覆盖新选择。
- [ ] 无评论、无热门划线、Key 失效、断网显示合适状态，可重试。
- [ ] “阅读全文”正确打开官方返回的 URL；缺少链接时打开官网。
- [ ] 网页扫码登录成功，正常阅读；网页内划线评论由官网提供。
- [ ] 重启后网页会话保留；“退出网页账号”确实清除 WebKit 会话。
- [ ] 断开 API 后远程数据清空，本地阅读可继续。
